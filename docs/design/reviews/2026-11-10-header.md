- 依頼の内容: 「ヘッダーがしょぼいので、少し良くしてください。」全ページ共通のヘッダの、小さな変更で印象が変わる改善案を 1 つ出す。
- 見た画面と幅: `/` と `/articles/top`。幅 360px と 1280px、ライトとダーク（ローカルの開発サーバー、フィクスチャのデータ）。
- 撮ったスクリーンショットの置き場所: `C:\Users\yoichiro\AppData\Local\Temp\claude\2f08a8f19ce146d2\f7629af3-2b39-451e-a920-0dfa8139a865\scratchpad`（`before-*.png` が現状、`after-*.png` が案、`focus-*.png` がキーボード操作のときの枠）。

## 結論

題名の行を、画面の端から端までの基調色の帯にする案を勧める。帯は文字だけのヘッダに「このサイトの顔」を作り、題名とタブの段の違いをはっきりさせる。高さは増えず、360px でのヘッダの下端は 140.2px → 133px（`/`）、197.2px → 182px（`/articles/top`）と、むしろ上がる。

最優先で直すことは次の 3 つで、下の 1 つの差分で全部直る。

1. 題名の行を基調色の帯にする（H-1）。
2. 現在のタブに、期間の選択と同じ薄い基調色の地を敷く（M-1）。
3. 題名の押せる高さを 44px にする（M-2）。

## 指摘

件数: 高 1、中 2、低 0。すべて全画面共通で、直す場所は `SiteHeader.module.css` と `globals.css`（TSX は要素 1 個の追加）。

### H-1 基調色が見えず、ヘッダがサイトの顔になっていない

- 画面と場所: 全画面の `SiteHeader`。
- いまの状態: 題名は 18px の太字の文字だけで、背景は本文と同じ `--color-surface`（`before-top-1280-light.png` の上端）。基調色は現在のタブの下線 4px にしか出ていない。
- 問題: 本文との境目が 1px の罫線だけで、開いた人が「どのサイトの何の画面か」を受け取る手がかりが弱い。題名とタブがどちらも白地の黒い文字なので、段の違いが文字の太さの差でしか分からない。
- 直す案: 題名を `.brand` の帯に入れ、背景を新しいトークン `--color-band` にする（下の差分）。文字の大きさは 18px のままにし、h1（360px で 24px、広い画面で 32px）より小さく保つ。主役は画面ごとの問いの h1 であり、題名を大きくすると競合する。
- 重要度: 高

### M-1 現在のタブの印が弱く、ほかの選ぶ部品と見た目が違う

- 画面と場所: `SiteHeader` の主タブ（`.link[aria-current]`）。
- いまの状態: 太字と下線 4px だけ。一方、すぐ下の期間の選択（`PeriodPicker`）と `ArticleTable` の選んでいるボタンは、`--shade-1`（ダークは `--shade-2`）の地と下線 4px で示している（`before-articles-360-light.png`）。
- 問題: 同じ「選んでいる」状態が、部品によって違う見た目になっている。360px の 3 列 × 2 行では、下線がタブの行の間に浮いて、どのセルの線かがやや読み取りにくい。
- 直す案: `.link[aria-current]` に地を敷く。値は `PeriodPicker` と同じ段にする（新しいトークン `--color-tab-current`）。太字と下線は残すので、色だけに頼らない。サブナビ（`.subLink`）には地を敷かず、太字と下線のままにして、主タブより一段弱く見せる（記事の画面で地のあるタブが 2 つ並ばない）。
- 重要度: 中

### M-2 題名のリンクの押せる高さが 23.4px しかない

- 画面と場所: `SiteHeader` の `.title`。
- いまの状態: 実測で高さ 23.4px（360px、1280px とも）。
- 問題: 「全体」に戻るリンクとして押す人がいるが、指では押しにくい。05 §2.9 の 44px の下限にも満たない。
- 直す案: `.title` に `min-height: var(--tap-min)` を与え、帯の高さをリンクの高さで決める（下の差分）。実測で 44px になった。
- 重要度: 中

## 改善案

### 変更の内容と選んだ理由

題名の行だけを基調色の帯にし、タブの段は白いまま（ダークは濃紺のまま）にする。選んだ理由は次のとおり。

- 変更が小さいわりに印象が変わる。増やす要素は帯の `div` 1 個で、タブの並びと `aria-current` の仕組みには触らない。
- 帯は高さを足さない。いままで題名の上下にあった余白（上 12px、下 8px）を帯の内側に振り替え、帯からタブを間をあけず続ける。
- 基調色の面積が増えるのは上端の 44px だけで、数字や図より目立たない。
- 別案: 上端に 4px の基調色の線と CSS の小さな図形を足す案は、変更はさらに小さいが「しょぼい」印象がほとんど変わらないので採らない。

### 測った値（案を当てた前後）

| 画面 | 幅 | ヘッダの下端（いま） | ヘッダの下端（案） | h1 の上端（いま → 案） |
| --- | --- | --- | --- | --- |
| `/` | 360px | 140.2px | 133px | 223.8px → 216.6px |
| `/articles/top` | 360px | 197.2px | 182px | 280.8px → 265.6px |
| `/` | 1280px | 99.4px | 92.2px | 159.2px → 152px |
| `/articles/top` | 1280px | 156.4px | 141.2px | 216.2px → 201px |

- 主タブは 360px で 2 行（3 列 × 2 行のまま）、タブの高さの最小は 44px。ページの横のはみ出しは 0。ライトとダークで同じ値。
- 題名の文字の左端は 16px（1280px では 176px）のままで、主タブのリンクの左端と h1 の左端にそろう。

### コントラスト比（WCAG の計算式）

| 組み合わせ | ライト | ダーク | 目安 |
| --- | --- | --- | --- |
| 題名の文字 と `--color-band` | 8.57:1（`#ffffff` / `#1a4c8b`） | 8.05:1（`#e6edf3` / `#214772`） | 4.5:1 |
| タブの文字 と `--color-tab-current` | 13.22:1（`#1c2128` / `#dbeaf9`） | 8.05:1（`#e6edf3` / `#214772`） | 4.5:1 |
| 下線とフォーカスの枠（`--shade-5`）と `--color-tab-current` | 7.00:1（`#1a4c8b` / `#dbeaf9`） | 5.63:1（`#a3cbf5` / `#214772`） | 3:1 |
| 帯 と ページの面（`--color-surface`） | 8.57:1 | 1.95:1 | 情報を持たない飾り |
| 地（`--color-tab-current`）と ページの面 | 1.22:1 | 1.95:1 | 情報を持たない飾り |

ダークの帯と面の差、タブの地と面の差は 3:1 に届かないが、帯は文字の背景で、タブの現在地は太字と下線で伝えているので、地が見えなくても意味は失われない。

### 案を入れるときに一緒に直すこと（フォーカスの枠）

帯を敷くと、題名のフォーカスの枠（`--shade-5`）がライトの帯の色と同じになって見えなくなる。また、帯に接する 1 行目のタブでは、枠の上辺が帯に重なって消える。次の 2 つを差分に含めた（`focus-top-360-light.png`、`focus-tab-top-360-light.png` で確認）。

- `.title:focus-visible` は枠を `--color-on-band` にし、内側に描く。文字に枠が触れないよう、`.title` に左右の padding を持たせ、同じ量の負の margin で文字の左端を保つ。
- `.link:focus-visible` と `.subLink:focus-visible` は、枠を内側に描く。
